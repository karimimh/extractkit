## Best ideas for a solo web developer

### 1. Accessibility monitoring SaaS

Build a tool that crawls websites weekly and gives businesses a dashboard of accessibility problems.

**Users:** agencies, SaaS companies, e-commerce stores.
**Features:** page crawl, WCAG issue detection, screenshots, severity scores, client-ready reports, “fixed vs new issues” tracking.
**Pricing:** £19–£199/month.
**Why good:** technical enough to differentiate, easy to demo, recurring by nature.

### 2. LLM prompt-injection tester

A SaaS that tests AI chatbots and AI agents against common attack patterns.

**Users:** companies adding AI support bots, AI agents, internal copilots.
**Features:** prompt attack library, test runs, risk score, leaked-data detection, unsafe-action detection, regression tests.
**Pricing:** £49–£499/month.
**Why good:** AI adoption is increasing, but many teams lack AI security expertise.

### 3. Technical SEO crawler for JavaScript-heavy sites

A crawler that shows what Google-like bots can or cannot see.

**Users:** SEO agencies, SaaS companies, marketplaces.
**Features:** rendered HTML comparison, missing meta tags, broken schema, canonical issues, page speed history, sitemap checks.
**Pricing:** £29–£299/month.
**Why good:** strong recurring use case and very web-development-native.

### 4. Cookie and tracking script scanner

A SaaS that scans websites and reports cookies, trackers, pixels, third-party scripts, and risky embeds.

**Users:** agencies, legal consultants, marketing teams.
**Features:** crawler, script classification, cookie table, consent banner checks, change alerts, exportable reports.
**Pricing:** £19–£149/month.
**Why good:** every business website changes scripts over time.

### 5. AI support-ticket pattern detector

Connects to Zendesk, Intercom, Freshdesk, Gmail, or Help Scout and finds repeated customer problems.

**Users:** SaaS companies, e-commerce brands, support teams.
**Features:** ticket clustering, weekly issue reports, sentiment trends, product bug detection, suggested help docs.
**Pricing:** £49–£399/month.
**Why good:** clear business value: fewer support tickets and better product decisions.

### 6. API contract monitoring SaaS

Monitors APIs for uptime, response shape changes, schema changes, latency, and breaking changes.

**Users:** SaaS companies, agencies, internal dev teams.
**Features:** scheduled tests, JSON schema validation, webhook alerts, status page, historical diffs.
**Pricing:** £15–£199/month.
**Why good:** simple MVP, developer-friendly, recurring pain.

### 7. RAG knowledge-base freshness monitor

For companies using AI chatbots trained on docs, this checks whether the chatbot’s knowledge base is stale or incomplete.

**Users:** AI chatbot owners, SaaS docs teams, support teams.
**Features:** crawl docs, compare against vector database, detect outdated pages, missing sources, broken links, hallucination-prone gaps.
**Pricing:** £49–£499/month.
**Why good:** more companies are building AI chatbots, but maintaining the knowledge layer is painful.

| Rank  | Idea                          | Why                                                                               |
| ----- | ----------------------------- | --------------------------------------------------------------------------------- |
| **1** | Accessibility monitoring SaaS | Strong fit for web developer skills, clear recurring need, agencies can resell it |
| **2** | LLM prompt-injection tester   | High-growth technical niche, less crowded than generic AI tools                   |
| **3** | API contract monitoring       | Easier MVP, technical audience, low customer education needed                     |

My personal pick: **Accessibility Monitoring SaaS for agencies**.

Do not target “everyone with a website.” Target:

> “Small web agencies that want to send monthly accessibility reports to their clients.”

That gives you a SaaS with recurring value, a clear buyer, and a product that genuinely requires your web development skill.
